## 波形「真根因」+ 用户三连需求（用户 2026-09-16 下午实测后）
- **波形不动真根因 = Canvas 测量高度 0**（不是电平刻度！）：`VoiceWaveform` 调用点只给 `fillMaxWidth()`，Compose Canvas 本体是 Spacer，高度约束宽松（min=0, max=32dp）→ 测成 0 高 → maxH=0 → 所有条贴 2px 最小值 = 静止细线（0 高布局不裁剪所以细线可见）。上游没事是因为 AnimatedSwitcher 用 `StackFit.expand` 强制撑满 32dp——移植时漏了这个语义。**改 dB 归一化当然没用：高度是 0，电平多大都白搭**。修：组件内 `WAVE_SLOT_HEIGHT_DP=32f` 兜底 `.height(32.dp)`（调用方显式给高度时以其为准）。
- **教训（重要）**：Compose `Canvas`/`Spacer` 在宽松高度约束下测 0 高是「出现但不动」类 bug 的隐藏来源；1:1 移植 Flutter 时 `StackFit.expand`/`SizedBox(height:)` 的约束语义必须落成显式 `.height()`。上一轮把根因误判成归一化刻度——几何没验证（没跑布局断言）就先改了数据层。
- **停止后文字立刻上屏**：`finishCloud` 重写为主线程零阻塞——点停止立刻回 Idle（录音行收起），worker join(500)+`session.finish()`（HTTP）全在后台线程，完成后回填。partial 本来就实时在输入框，无观感空窗。
- **跨代竞态顺手修**：全局 `cloudRunning` 换成每代会话独立 `AtomicBoolean cloudActive`（否则停止后立刻再点麦克风，老一代收尾线程翻全局标志会误杀新一代 worker）。
- **■/✓/✕ 三键触感**：走项目惯例 `Haptics.light(view)` + `LocalHapticsSettings.globalEnabled` 门控（ChatVoiceRecordingRow 内 `tapHaptic()`）。
- 测试：新增 `VoiceWaveformLayoutTest`（2 例：宽松约束下槽高=32dp / 显式高度优先），Robolectric qualifiers `160dpi` 让 1dp=1px；`getUnclippedBoundsInRoot()` 返回 Dp（`.value` 取 Float，`.height` 会撞 Modifier.height 扩展——用 `bottom-top`）。全量门禁绿，装机。
