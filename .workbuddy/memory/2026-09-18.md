## SVG 产物能保存/分享 + 存储页认 .svg（用户「生成的这个 svg 点击下载不了，存储数据的图片里面怎么也没有记录」）
- 两个根因都在「SVG 被当二等公民」：
  ① `saveImageToGallery` 是「读字节 → 按 image/png 写进 MediaStore」，SVG 的**文本字节**当 PNG 存进去 → 相册里坏图（表现为「点保存没反应」）；分享同理直发原文件。

- 修：`isSvgUrl` + `svgToPng`（AndroidSVG → 位图 → PNG，长边 2048 上限、缩放 1~3 倍；`svgPngSize` 抽纯函数）前置转换；`isImageFileName` 抽顶层纯函数并补 `.svg`。
