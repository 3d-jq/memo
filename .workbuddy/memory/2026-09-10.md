## 引用胶囊垂直对齐修正（用户实测"和输出文字没有水平对齐"）

- 根因：照抄了原项目的 `PlaceholderVerticalAlign.TextCenter` + `translate(0, -2dp)`，但 **Compose 的 `TextCenter` 对齐的是「行盒中心」**（浮在 CJK 字形上方），再叠 -2dp 上移 → 角标明显悬空。Flutter 的默认基线对齐语义不同，数值不能照搬。

- 截图（adb screencap）核对确认所有角标与同行文字视觉齐平；门禁全绿 + 已装机。

### API 血泪（`GraphicsLayer` 截图，Compose ui-graphics 1.8.3）
- `rememberGraphicsLayer()` 在 **`androidx.compose.ui.graphics`**（`GraphicsLayerScopeKt`）；类型 `androidx.compose.ui.graphics.layer.GraphicsLayer`。
- 录制是 **`DrawScope` 上的扩展**（不是 `GraphicsLayer` 成员）：`layer.record(IntSize) { this@drawContent.drawContent() }`。
- 回放 `drawLayer(layer)` 在 **`androidx.compose.ui.graphics.layer`** 包（**不是** `.drawscope`）。
- `toImageBitmap()` 是 **suspend 成员**，无顶层扩展可 import。
- 参数名在接口默认方法上解析不到 → 若报 `No parameter with name 'x'`，改**位置参数**。
